# 视频项目

每部视频使用一个独立根文件夹。工作台新建项目默认放在本目录，也可以选择其他位置；打开已有项目会登记原位置。

项目包含 `project.json`、`AGENTS.md`、`.agents/skill_registry.md`、项目 Skill 副本以及 `deliverables/0_admin` 到 `deliverables/4_edit`。媒体、生产状态和 SQLite 均跟随项目。平台仓库默认不提交这里的私人项目内容。

工作台左侧选择项目后，点击「在 Codex 中创作」复制绑定该项目的指令或启动命令。每个创作阶段重新读取该项目 Registry；已绑定的对话不跟随其他窗口的项目切换。

完整备份应先关闭工作台，再复制整个项目文件夹。带着 `project.json` 在另一工作区打开即可保留项目身份；同一工作区不允许同时登记相同 ID 的两个副本。不要在一个视频项目内部嵌套另一个视频项目。
