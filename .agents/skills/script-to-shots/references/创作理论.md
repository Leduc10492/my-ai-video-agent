# 植入拆镜流程的创作理论

> 2026-10-18 · 只收能变成**具体规则**的理论。每条都写明它在《剧本转分镜.md》哪一步起作用、规则是什么、由谁检查，并用 SC003–004 举例。
> “程序查”表示编译器能从舞台和镜头数据里算出对错；“模型守”表示只能写进导演 agent 的守则，靠审片发现。

## 总表

| 理论 | 一句话 | 放在哪一步 | 谁检查 |
|---|---|---|---|
| 麦基：节拍与价值转换 | 没有价值变化的不算节拍；变化最大的那拍最值得给镜头 | 第 3–4 步 | 模型守 |
| 希区柯克：悬念与惊奇 | 让观众先知道炸弹在桌下，再反复提醒 | 第 3 步、第 5 步 | **程序查** |
| 希区柯克法则 | 东西在画面里占多大，等于它此刻多重要 | 第 4 步 | 半程序 |
| 库里肖夫效应和马梅的“无修饰画面” | 单个镜头不带情绪，意义来自前后两个镜头的拼接 | 第 2 步、提示词 | **程序查**（禁词） |
| 布鲁斯·布洛克：对比与相似 | 画面强度要跟着故事强度走，靠对比升、靠相似降 | 第 4 步、审片页 | **程序画曲线**，人看 |
| 默奇：剪辑六法则和视线追踪 | 剪辑优先级是情绪、故事、节奏、视线、平面、空间；快切时前后两镜主体位置要接得上 | 第 5 步 | **程序查**（视线） |
| 阿里洪：三角形机位和轴线 | 对话双方连线是轴线，机位不能越过 | 镜头语法库、第 5 步 | **程序查** |

## 1. 麦基：节拍与价值转换

**说法**：一场戏由节拍组成。每个节拍里，人物的某个价值（安全/危险、服从/反抗、被信任/被误解）从正变负或从负变正。没有变化的段落不算节拍，只是信息。

**规则**：

- 第 3 步给每个节拍写“价值：前 → 后”。写不出变化的，并进相邻节拍，不单独分镜头组。
- 变化幅度最大的节拍是全场转折点，第 4 步的重量必须是最高。

**本场**：

| 节拍 | 价值 |
|---|---|
| D03 你演得不像他 | 一切按剧本 → 不对劲 |
| A07 怀里是年轻男人 | 不对劲 → 这场戏是假的 |
| A09 玻璃开裂 | 安全 → 危险（只有江北知道） |
| A15 江北没有倒 | **服从 → 反抗**，全场最大的转折 |
| A19 碎片悬停 | 危险 → 得救 |
| A23 嘘声 | 英雄 → 被当成坏人 |

A15 只有一句“江北没有倒”，在剧本里很短，但按价值它是全场最重的一拍。v3 样例只给了它 C19 一个镜头。按这条规则，它应该比赵凯登场更值得设计。

## 2. 希区柯克：悬念与惊奇

**说法**：桌子下面有颗炸弹。如果观众不知道，炸了只有几秒的惊吓。如果观众先看到了炸弹，接下来五分钟的闲聊都会让人坐立不安。

**规则**：

- 第 3 步信息表里，凡是“观众知道危险、在场的人不知道”的时间段，标为**悬念窗口**。
- 悬念窗口里，危险物必须每隔一段时间重新出现在画面里，哪怕只是背景。间隔我先定为 8 秒，以后看片调。
- 编译器能查：从舞台算出危险物（玻璃）在每个镜头里是否可见，窗口里连续超过 8 秒没出现就报警。

**本场**：悬念窗口是 A09 到 A18，也就是玻璃开始裂到玻璃爆裂。按 v3 样例的时间轴大约 33 秒到 77 秒，共 44 秒。我查了样例的编译结果：赵凯登场那一组里，H4 群众反应镜头的背景里有裂开的玻璃，C14、H6 也有，所以最长的空档只有 4 秒左右，这条现在是满足的。但这是我写镜头时碰巧做到的，没有任何规则要求。加了这条检查以后，这一点就有了保证。

## 3. 希区柯克法则

**说法**：一个东西在画面里占多大，应该等于它此刻在故事里有多重要。

**规则**：已经写进调研结论。第 3 步信息表标出每个动作是谁知道的，重要度高的人或物，景别更近、占画面更大。第 4 步的景别建议由程序按重要度给出初值，导演 agent 可以改，但要写原因。

**本场**：A20“他只看见小女孩的眼睛”，这时最重要的是小女孩的眼睛，应该是特写，而不是 v3 样例 C27 的近景。

## 4. 库里肖夫效应和马梅的“无修饰画面”

**说法**：库里肖夫把同一张没有表情的脸，分别接在一碗汤、一个死去的孩子后面，观众说演员分别演出了饥饿和悲伤。马梅在《导演功课》里把它变成方法：每个镜头只拍一个不带情绪的事实，情绪由两个镜头拼接产生。

**规则**：

- 镜头描述和提示词里，禁用情绪词和心理词，例如震惊、绝望、意识到、心里一沉、眼神复杂。只写看得见的：停住、不眨眼、手松开。
- 反应镜头的意义来自下一个镜头拍了什么，所以要成对设计：脸，然后他看见的东西。
- 编译器能查：维护一张禁词表，提示词里出现就报错。

**为什么要这条**：EP001 的文字链分析里，有一类错是“情绪词被模型拍成了动作”，比如写了“震惊”，模型就让人物夸张地往后仰。这条规则从源头上消除这类问题。

## 5. 布鲁斯·布洛克：对比与相似

**说法**：出自《视觉故事》。画面有几种可控的要素：景别、角度、运动、剪辑速度、色调。相邻镜头这些要素差别大（对比），观众感到的强度就高；差别小（相似），观众就平静。故事强度曲线和画面强度曲线应该同步。高潮之前要先压低，把对比留到高潮用。

**规则**：

- 编译器给每个镜头算一个画面强度分，依据是：和上一镜相比景别跳了几级、角度有没有变、是否运动、是否升格、成片时长多短。
- 第 4 步的节拍重量连成故事强度曲线。
- 审片页上把两条曲线叠在一起画。人只看一件事：两条线的起伏是不是同步。

**本场**：赵凯登场（广告式）和江北救人（反广告式）这一对，用的就是对比。按这条理论还能往前推一步：江北的决定（A14–A15）是全场最强的节拍，但它前面紧挨着赵凯登场的高强度快切。决定这一段要用相似来压，比如长镜头、不动、平拍，让这一下的“静”和前面形成对比，而不是继续快切。

## 6. 默奇：剪辑六法则和视线追踪

**说法**：出自《眨眼之间》。一个剪辑点好不好，按重要性排是：情绪 51%、故事 23%、节奏 10%、视线追踪 7%、画面平面关系 5%、三维空间连续 4%。前面的比后面的重要，必要时可以牺牲后面的。视线追踪的意思是，观众在上一镜结尾看着画面的某个位置，下一镜的主体最好也在那附近，眼睛不用找。

**规则**：

- 编译器的警告按这个顺序分级。空间类的小问题（比如人物在画面里的左右位置稍有跳动）在情绪需要时可以放过；对口型错位、该看到的没看到这类故事问题不能放过。
- 快切段（成片 1.5 秒以内的连续镜头）检查视线：编译器从舞台算出主体在上一镜结尾和下一镜开头的画面水平位置，跳动超过画幅的一半就提醒。

**本场**：H1 到 H5 是一组 1–1.5 秒的快切，最适合用这条检查。

## 7. 阿里洪：三角形机位和轴线

**说法**：出自《电影语言的语法》。两个人对话时，两人之间的连线是轴线，所有机位都放在轴线同一侧，形成一个三角形。越过轴线，两个人在画面里会互换左右，观众就迷失了。

**规则**：

- 镜头语法库的“对白交锋·正反打”按三角形机位写成固定的机位组。
- 编译器能查：对话进行中，从舞台算出两人连线，镜头机位在轴线另一侧就报错。想越轴，必须先有一个跨轴的运动镜头或中性镜头，导演 agent 要写原因。

**本场**：D03–D05 江北和人质贴身对话，C05、C07 是正反打，可以直接用这条检查。

## 没收进来的

- **救猫咪、英雄之旅**这类结构理论：管的是整部片的段落，不管镜头。剧本阶段用麦基就够了。
- **爱森斯坦的蒙太奇分类**：理论价值高，但很难落成可检查的规则。“外面欢呼、里面只有江北看见裂纹”这种对比剪辑，已经由布洛克的对比原则和库里肖夫覆盖了。
- **短剧“前 3 秒钩子”之类的平台经验**：属于剧本和剪辑层的决定，不是拆镜理论。以后做成片节奏时可以再加。

## 理论管不到的地方

上面这些能保证镜头**清楚、有重点、有起伏**，但保证不了**有味道**。好的拍法很多来自看过的具体片段。下一步可以考虑建一个参考片段库：从真实电影里挑 20–30 个段落，按 PSL 的写法标注成镜头表，再按戏剧功能归类。导演 agent 设计镜头组时，查语法库，也查这些真实例子。
