# 剧本格式规范：标准好莱坞格式

> 2026-10-18 定稿（Lei 选定：标准好莱坞格式，先从简）
> 文件用 Fountain 纯文本（`.fountain`），以后放进剧本编辑工作台也能直接解析。样例：[SC003–004 剧本](../examples/SC003-004/剧本.fountain)

## 六种元素

| 元素 | 写法 | 例子 |
|---|---|---|
| 场景标题 | `INT.` 或 `EXT.` + 地点 + ` - ` + 时间，单独一行 | `INT. 东城商业银行 大厅 - DAY` |
| 动作 | 普通段落，只写拍得到、演得出的东西 | `江北低头，看自己手腕内侧贴着的群演表。` |
| 人物名 | 单独一行；中文名前加 `@` | `@江北` |
| 括号提示 | 人物名下一行，一两个词 | `(小声)` |
| 对白 | 括号提示下一行，不加引号 | `……什么？` |
| 转场 | 只在必要时写，单独一行 | `CUT TO:`，全剧开头 `FADE IN:`、结尾 `FADE OUT.` |

时间只用 `DAY`、`NIGHT`；同一时间段接着发生用 `CONTINUOUS`。人物第一次出场时，在名字后括号里写年龄和一句外形。

## 声音标记

写在人物名后面：

- `(O.S.)`：人就在这场戏的现场或通讯里，只是不在画面上。例如耳麦里的导演。
- `(V.O.)`：现场的人听不到的声音，包括旁白、回忆里的声音、内心独白。例如老孙那句闪回。

## 屏幕和纸上的字

用 `.INSERT - 物件名`（前面的点是 Fountain 的强制场景标题写法，不加会被误认成人物名），下一行写字的内容，然后 `BACK TO SCENE` 回到场景。例子：群演表、手机直播画面。

## 不写的东西

- 镜头和剪辑术语：特写、主观镜头、“我们看到”。这些交给镜头层。
- 内心活动：想、意识到。要改成看得见的动作，比如“江北一愣”改成“江北停住”。
- 比喻：“像被看不见的手按住”这种拍不出来，删掉或改成实际发生的事。
- 站位细节：哪只手、在左边还是右边，交给舞台层。

## SC003–SC004 改写时动过的地方

情节和台词都没改，只动了下面四类：

- 场景标题按空间拆成大厅和门外广场两块，中间用 `CONTINUOUS` 连接。
- “江北一愣”改成“江北停住”。
- 删掉了两个比喻：“像排练过一百次”和“像被看不见的手按住”。
- 删掉了“慢镜头”“现实速度恢复”这两个镜头术语。碎片停在半空，本身就是故事里真的发生的事，照写。
