# 剧本转分镜

一次只拆**一场戏**（或几场连续的戏）。核心原则是**世界只写一次，镜头只负责取景**：

- 站位、手、道具、状态只在舞台里写一次。
- 镜头只写从哪看、看哪几秒、看多大。
- 画面左右、谁拍得到、谁闭嘴、画面长什么样，都由编译器算，不靠模型写。
- 俯视图不当图片喂给视频模型。编译器把它翻成提示词里的两行文字：
  - `画面`：谁在画面左中右，正面、侧面还是背面；
  - `场地关系`：机位离主体几米，前景、中景、背景各有什么，主体和旁人、固定物相距几米，机位在主轴哪一边。

工具和参考都在本 skill 目录里（下面的路径都相对于 SKILL.md 所在目录）：

| 文件 | 用途 |
|---|---|
| `scripts/parse_fountain.py` | 第 1 步，切分剧本 |
| `scripts/compile.py` | 编译器：检查、提示词、审片页。需要 Python 3 和 PyYAML |
| `scripts/review_template.html` | 审片页模板，必须和 compile.py 放在同一目录 |
| `references/镜头语法库.yaml` | 按戏剧功能分类的镜头组，带切点 |
| `references/剧本格式规范.md` | 剧本格式 |
| `references/剧本转分镜.md`、`references/创作理论.md` | 设计依据 |
| `examples/SC003-004/` | 完整样例，格式不确定时照它写 |

## 输入

一个 Fountain 剧本文件（`.fountain`）。格式按 `剧本格式规范.md`：

- 场景标题 `INT./EXT. 地点 - DAY/NIGHT`。
- 中文人名前加 `@`。
- `(O.S.)`、`(V.O.)` 写在人名后面。
- 屏幕和纸上的字用 `.INSERT - 物件` / `BACK TO SCENE`。

剧本里如果有镜头术语、心理描写、比喻，先在剧本里改掉，再开始拆。

## 输出：一个场景目录

```
<场景>/
  剧本.fountain
  00_剧本切分.txt     程序生成
  01_拆解.yaml        第 2–4 步，人主要审这个
  02_舞台.yaml        第 5 步
  03_镜头.yaml        第 6 步
  输出/               编译器生成：提示词.md、问题.txt、审片.html
```

## 步骤

### 1. 切分（程序）

```
python3 scripts/parse_fountain.py <场景>/剧本.fountain <场景>/00_剧本切分.txt
```

每个元素得到一个编号：S 场景，A 动作段，D 对白，I 插入。数字是剧本里的先后顺序。后面所有东西都引用这些编号。

### 2. 义务表（`01_拆解.yaml` 的 `义务`）

每个编号写一条：

```yaml
A11: {类: [构图要求], 要: 人群的脸朝车，裂开的玻璃在背景里, 同框: [人群, 玻璃幕墙]}
```

**类**只能从下面挑，一句可以挑几个：

| 类 | 怎么认 | 对镜头的义务 |
|---|---|---|
| 交代 | 地点、人物首次出场 | 一个看清谁在哪的镜头；首次出场的人要有自己的一镜 |
| 动作 | 看得见的动词 | 一个动词一镜，一句几个动词就拆成几镜 |
| 停顿 | 停住、没回答、没做某事、“一秒” | 一个有时长、什么都不发生的镜头；不能并进下一个动作 |
| 视线 | 看、抬眼、只看见 | 两镜成对：先拍看的人，再拍他看见的 |
| 揭示 | 观众得到新信息 | 先给证据，再给对照，中间不加解释 |
| 构图要求 | 两样东西的关系必须在一个画面里成立 | 写 `同框`，编译器验证 |
| 声音 | O.S.、V.O.、无声 | 画面给听的人；V.O. 期间画面里没人张嘴 |
| 对白 | 一句台词 | 一句一个对口型镜头 |
| 插入 | `.INSERT` | 一个特写，内容后期合成 |

`要` 只写看得见、听得见的东西，不写情绪词。确实不需要镜头的，加 `可省: true` 并写原因。

### 3. 节拍和信息（`节拍`、`悬念`）

```yaml
节拍:
  - {名: 江北的决定, 从: A14, 到: A15, 价值: 服从 → 反抗, 知道: [观众, 江北], 重量: 3, 秒: 7, 拍法: 镜头语法库里的名字}
悬念:
  - {从: A09, 到: A18, 危险: 玻璃幕墙, 观众和谁知道: [江北], 谁不知道: [赵凯, 人群]}
```

**价值**（麦基）：每个节拍写人物的价值从什么变成什么。写不出变化的，并进相邻节拍。变化最大的那一拍重量最高。

**知道**：这一刻谁知道什么。

- 观众和主角知道、别人不知道：用“只有一个人看见危险”。
- 观众知道、剧中人不知道：标为悬念窗口（希区柯克的“桌下炸弹”），危险物要隔一会儿就入一次画。
- 主角不知道的东西，不给主角主观视角。

### 4. 节奏预算

- **重量**：1 是带过，3 是全场最值钱。
- **秒**：这一段在成片里留多久。各段加起来接近 `目标时长`。
- **拍法**：重量 2–3 的段落，从 `references/镜头语法库.yaml` 挑一套，并按它的“切点”切。
- **赵凯和江北式的对照**：两段成对设计，一段用对比（仰拍、升格、快切），另一段用相似（平拍、手持、少切）。
- **重量 3、又不是动作的段落**：用长镜头，不要快切。

### 5. 舞台（`02_舞台.yaml`）

只写物理世界，不写镜头。格式照样例：

- **基本信息**：`title`；`画幅`（"9:16" 或 "16:9"，分镜草图和景别都按它算）。
- **space**：
  - `zones`：`when` 写区域条件，`ref` 是场景参考图，`kind` 填室内或室外。
  - `fixtures`：场景里固定的东西。`line` 是两个端点，`h` 是高度（米），1.2 以下算绳子。
  - `主轴`：这场戏的主方向，例如 `{从: [0, -10], 到: [0, 12], 名: 银行大厅 → 广场}`。`名` 用“A → B”写，提示词里会写成“站在 A 朝 B 看，机位在右边”。
- **cast**：
  - 每人写 `ref` 参考图、`look` 外形，`h` 身高（默认 1.7，孩子要写）。
  - 群体加 `group: true`，物体加 `object: true`。
  - 群体在 set 里可以写 `span`（左右范围）和 `rows`（几排）。
- **timeline**：每条事件有 `t`（开始秒）和 `dur`（时长）。可加 `src` 指回剧本编号，悬念检查要用它定位时间。事件类型：
  - `set`：设置人物的位置、朝向、手、姿态。
  - `act`：一个动作。可带 `needs: 正面`、`releases`、`pose_after`、`ambient`。
  - `move`：移动。和动作是同一件事时加 `same_action`。
  - `say`：画内台词。
  - `sound`：画外声音。
  - `hold`：保持不动。
  - `change`：场景状态变化，带 `how` 写看得见的过程。
  - `overlay`：后期合成的字。
  - `exit`：人物离开，任何镜头都不能拍到这个过程。
- **坐标**：俯视，单位米。人物自己的左右由朝向推出来，不要写“画面左”。
- **写法**：动作写成看得见的样子，不写震惊、意识到这类词。

### 6. 镜头（`03_镜头.yaml`）

每镜一行：

```yaml
- {id: C18, from: 59, to: 61, at: [0.4, -6.5], look: [0.5, 6.6], size: 全景, height: 1.7, 兑现: [A14], why: 越过江北肩头：玻璃正对着第一排的小女孩}
```

- **必填**：`id`、`from`、`to`（舞台时间）、`at`（机位坐标）、`look`、`size`、`兑现`、`why`。
  - `look` 写人名或坐标。坐标可写第三个数，表示看向的离地高度，拍手、拍卡片时要写。
  - `size` 从远景、全景、中景、中近景、近景、特写、大特写里选。
  - `兑现` 写这一镜负责义务表里的哪几条。
- **可选**：
  - `frame`：只拍某部位，比如脚、手、眼睛，必须配特写或大特写。
  - `height`：机位离地高度。
  - `angle`、`move`。
  - `speed: 升格`：升格镜头里不能有对口型台词。
  - `pov`：某人的主观视角。
  - `cut`：成片留几秒。生成按 2–4 秒，成片可以只留 1–1.5 秒。
  - `越轴`：有意越轴时写原因，编译器就不再报左右对调。
- **插入镜头**：写 `insert: 物件名`，不写 `at`、`look`。
- **时长**：单镜 2–5 秒。
- **轴线**：对话时机位在两人连线的同一侧。

### 7. 编译和修

```
python3 scripts/compile.py <场景目录>
```

退出码 0 才算过。`问题.txt` 里的 ERROR 必须全部改掉，改的地方是舞台或镜头，不是提示词：

- **一镜多个动作**：拆镜头。
- **动作没人拍到、需要正脸却背对**：改机位或舞台朝向。
- **人物离开被拍到**：改机位。
- **升格配对口型**：去掉升格，或把台词挪出这一镜。
- **义务没有镜头兑现**：补镜头，或在拆解表里标 `可省` 并写原因。
- **构图要求不成立**：调机位，直到同框的东西都在画面里。
- **主体的脸被前景挡住**：换机位，或升高机位越过人群。
- **悬念窗口里危险物太久没入画**：让某一镜的背景带上它。
- **提示词里有情绪词**：回舞台把那句改成动作。

WARN 里的“左右对调（越轴）”：相邻两镜都拍到同两个人，他们在画面里的左右顺序反了。不是有意的就把机位挪回主轴同一侧；有意的（比如隔着玻璃的正反打）就在镜头里写 `越轴: 原因`。

WARN 逐条看，有理由的可以留，在交付时说明。

### 8. 交付

1. 把 `输出/审片.html` 发布为 Artifact。同一场戏改版时，发布到同一个链接。
2. 回复用户时只说三件事：
   - 一共多少镜、多少段；
   - 编译器拦下了什么、怎么改的；
   - 哪些 WARN 留着，为什么。
3. 不要在回复里复述镜头表，让用户看审片页。

审片页必须有两种查看方式，页面顶部用一组切换按钮切换，用户上次选的方式要记住：

- **按时间轴看（单镜，默认）**：从上往下依次是：
  - 时间轴；
  - 当前这一镜：左边是画面草图和俯视图，右边是检查结果、兑现的义务、这段时间舞台上发生的事、提示词；
  - 分镜板，横向一排，跟着当前镜头滚动。
  - 方向键或“上一镜／下一镜”逐镜翻。
- **总览（全部分镜）**：隐藏时间轴和单镜详情，所有分镜草图按网格铺开，每格写编号、景别、时长和这一镜的用途。点任意一格，切回单镜并定位到这一镜。
- **两种方式下都在最下面**：拆解表，写明每条义务由哪几镜兑现，红底是漏拍。

草图的画法：按机位投影，画幅按舞台的 `画幅`。橙色是镜头主体，绿点表示在对口型，浅灰小人是远处的人。

改模板时，单镜详情里的俯视图和提示词不能被其他新加的内容挤到页面下面去。

## 已知限制

编译器里还有 SC003–004 银行场景的假设，换新场景时先检查：

- 朝向关键词“门外”和“大厅”；
- “透过玻璃”的判断按 y 的正负；
- 场景状态只认“玻璃幕墙”和“大门”；
- 俯视图的边界和警戒线是写死的；
- 碎片效果绑定了江北。

遇到新场景要先把这些改成从舞台数据里读，再拆镜。分镜草图是示意，不算遮挡以外的细节，人物一律画成简化小人。
